### 🚀 [Space Salvager](https://github.com/aleksejMarkovGit/SpaceSalvager)

A small 2D score-attack survival game written in **C++14** using **SFML 2.5.1**.

The project includes:

- real-time ship movement and a complete gameplay loop;
- custom collision detection and impulse-based collision resolution;
- damage, repair and scoring systems;
- semantic input handling;
- resource management;
- HUD and game-state logic;
- a CMake build for Linux and a Windows-oriented configuration.

The project is also used as a practical environment for developing skills in software architecture, object lifetime and ownership management, refactoring and cross-platform C++ development.
